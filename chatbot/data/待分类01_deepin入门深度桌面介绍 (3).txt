蓝牙设置
蓝牙能够实现短距离的无线通信，您可以通过蓝牙与附近的其它蓝牙设备连接，常见的蓝牙设备包括：蓝牙键盘、蓝牙鼠标、蓝牙耳机、蓝牙音响等。

notes：大多数笔记本电脑都配备有蓝牙模块，您只要开启蓝牙功能开关，而大部分台式电脑都没有配备蓝牙，您可以购买相关蓝牙适配器插入到电脑的USB端口中使用。

蓝牙开关
在控制中心面板首页，点击 moresettings。
点击 蓝牙，进入设置蓝牙界面。
点击蓝牙开关按钮，开启蓝牙功能。
蓝牙名称
在控制中心面板首页，点击 moresettings。
点击 蓝牙，进入设置蓝牙界面。
点击蓝牙名称旁边的编辑图标,输入新的蓝牙名称。
notes：修改蓝牙名称成功后同时自动对外广播蓝牙设备的新名字，需要其他设备重新进行搜索。

蓝牙设备
在控制中心面板首页，点击 moresettings。
点击 蓝牙，进入设置蓝牙界面。
在 其他设备 列表中，系统扫描附近的蓝牙设备并自动连接。
连接成功后自动添加到 我的设备 列表中。
在 我的设备 列表中，可以 断开连接 和 忽略此设备 操作。
网络设置
体验网上冲浪带来的乐趣！您可以在网络上浏览新闻、在线视频播放，也可以下载文件、聊天、网上购物等操作。

网络信息
在控制中心面板首页，点击 moresettings。
点击 网络详情，进入网络信息界面。
查看当前网卡的有线网络或无线网络信息。
有线网络
将网线插入电脑上的网络插孔。
将网线的另一端插入路由器或网络端口。
在控制中心面板首页，点击 moresettings。
点击 有线网卡 开关按钮，开启有线网络连接功能。
当网络连接成功后，在桌面将会弹出“已连接有线连接”的提示信息。
无线网络
连接无线局域网

在控制中心面板首页，点击 moresettings。
点击 无线局域网，进入无线局域网界面。
点击 无线网络 开关按钮，开启无线网络连接功能。
电脑会自动搜索并显示附近可用的无线网络。
选择需要连接的无线网络。
如果该网络是开放的，将自动连接到此网络。
如果该网络是加密的，请根据提示输入密码，点击 连接，然后将自动完成连接。
连接隐藏网络

在控制中心面板首页，点击 moresettings。
点击 无线局域网，进入网络信息界面。
点击 连接到隐藏网络，进入连接到隐藏网络界面。
输入隐藏网络名称、选择加密方式和密码。
移动网络
将移动网卡插入电脑上的USB接口中。
在控制中心面板首页，点击 moresettings。
系统根据移动网卡和运营商信息自动适配并自动连接网络。
点击 移动网络，查看详细设置信息。
宽带连接
新建宽带连接

点击 新建宽带连接，进入新建宽带连接界面。

在控制中心面板首页，点击 moresettings。
点击 宽带连接，进入宽带连接设置界面。
修改名称、帐户、密码、开启自动连接、设置IP地址以及开启其他认证服务。

系统代理
在控制中心面板首页，点击 moresettings。

日期和时间
自动同步
在控制中心面板首页，点击 moresettings。
点击 自动同步开关按钮，开启时间自动同步功能。
系统会通过网络自动同步系统默认时区的本地时间和日期。
设置时间和日期
手动设置时间和自动同步功能相互排斥，手动设置后自动同步功能会被关闭。

在控制中心面板首页，点击 moresettings。
点击 设置时间开关按钮，开启时间自动同步功能。
输入正确的时间和日期。
点击 确定。
添加时区
在控制中心面板首页，点击 moresettings。
点击 添加时区。
通过搜索或点击地图选择时区。
点击 确定。
编辑时区列表
在控制中心面板首页，点击 moresettings。
点击时区列表行末尾的 编辑。
此时时区列表上的时区行出现删除图标。
点击删除图标删除已添加的时区。

鼠标和触控板
在控制中心面板首页，点击 moresettings。
点击 左手/自然滚动/输入时禁用触摸板/插入鼠标时禁用触摸板 开关按钮，开启相关功能。
调节 双击速度 和 指针移动速度。
notes：请注意左手使用鼠标时左键和右键功能互换，自然滚动功能和苹果系统的滚动效果类似。

键盘和语言
您可以根据国家和地区，选择您的键盘输入习惯和布局以及查看、搜索、修改和自定义快捷键。

设置键盘属性
在控制中心面板首页，点击 moresettings。
调节 重复延迟/重复速度。
点击 请在此测试，按下键盘上任意字母不松，查看调节效果。
点击 大写锁定提示 开关按钮，开启相关功能。
设置键盘布局
系统默认的键盘布局一般是美式键盘，您可以添加其他的键盘布局。

添加键盘布局

在控制中心面板首页，点击 moresettings。
点击 键盘布局，进入键盘布局界面。
点击 添加键盘布局，进入添加键盘布局列表界面。
按字母或搜索需要添加的语言键盘布局。
删除键盘布局

在控制中心面板首页，点击 moresettings。
点击 键盘布局，进入键盘布局界面。
点击键盘布局后的 编辑 > 删除，选中需要删除的键盘布局。
切换键盘布局

在控制中心面板首页，点击 moresettings。
点击 键盘布局，进入键盘布局界面。
选择一个键盘布局进行切换。
当切换键盘布局成功后，在使用的语言后将显示为已选择。
设置系统语言
在控制中心面板首页，点击 moresettings。
点击 系统语言，进入系统语言界面。
选择或搜索需要切换的语言，系统将自动开始安装语言包。
语言包安装完成后，在使用的语言后将显示为已选择。
attention：更改系统语言时，键盘布局可能也会发生改变。重新登录时，请确保使用正确的键盘布局来输入密码。
