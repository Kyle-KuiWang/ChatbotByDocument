简介
ocenaudio 是一款跨平台、易于使用、快速且功能强大的音频编辑软件。ocenaudio 既适合普通用户编辑简单的音频文件，也适合专业用户编辑复杂的音频文件。
安装
sudo apt install com.ocenaudio.ocenaudio
卸载
sudo apt remove --purge com.ocenaudio.ocenaudio
